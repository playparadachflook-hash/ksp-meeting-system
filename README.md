# ระบบจองห้องประชุมออนไลน์ โรงพยาบาลโคกศรีสุพรรณ (KSP Meeting System)

โปรเจคปรับปรุงและพัฒนาใหม่ด้วย **Node.js + Express + SQLite (better-sqlite3)** จากระบบจองห้องประชุมเดิม (`metting` PHP/MySQL) โดยคงความสามารถเดิมทั้งหมด รองรับการเพิ่ม/แก้ไข/ลบข้อมูลใหม่ ปฏิทินจองห้องประชุม สร้างเอกสาร PDF ขนาด A4 และมีสคริปต์โอนย้ายข้อมูลเก่าจากฐานข้อมูล MySQL เดิมให้ใช้งานร่วมกับระบบใหม่ได้อย่างสมบูรณ์

## การติดตั้งและใช้งาน
```bash
npm install
cp .env.example .env
# โอนย้ายข้อมูลเก่าจากฐานข้อมูล MySQL เดิม (แปลงรหัสภาษาไทย TIS-620/UTF-8 อัตโนมัติ)
npm run migrate
# เริ่มทำงานเซิร์ฟเวอร์
npm start
```

เปิดใช้งานได้ที่ `http://localhost:3532`
